# sales-executive-performance-dashboard - Excel
Excel dashboard analyzing 20,000 sales records across 440 executives and 12 regions. Built using Pivot Tables, SUMIF, AVERAGEIF, charts and conditional formatting.

## Project Overview
An Excel-based business intelligence dashboard analyzing sales performance across 440 executives, 20,000 records, and 12 regions across India.

## Business Problem
The sales team needed a centralized view to identify top performers, underperforming executives, regional trends, and daily sales patterns to support data-driven decision making.

## Dashboard Features
- Top 10 and Bottom 5 executives by total sales
- Region-wise sales distribution (12 regions)
- Average target hit % by executive
- Daily sales trend analysis
- Region summary table with average target and sales

## Tools & Techniques Used
- Microsoft Excel
- Pivot Tables
- SUMIF, AVERAGEIF, UNIQUE, SORT formulas
- Conditional Formatting
- Bar Chart, Line Chart, Pie Chart
- Dashboard design with dark theme formatting

## Dataset
- Total Records: 20,000
- Sales Executives: 440
- Regions Covered: 12
- Key Metrics: Total Sales, Target Hit %, Daily Averages

## Key Insights
- Average sales across all executives: 275
- Average target hit rate: 55%
- Top performer: Manoj Kapoor (17,973 total sales)
- Lowest performer identified for coaching intervention
- Jaipur region leads with highest average sales of 277.0
